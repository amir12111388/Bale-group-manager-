# ربات مدیریت گروه بله - نسخه فارسی‌سازی‌شده

این نسخه از سورس مدیریت گروه برای **بله** بازطراحی شده و دستورات اصلی آن کاملاً فارسی شده‌اند. دستورات انگلیسی و اسلش‌دار قدیمی هم برای سازگاری همچنان فعال هستند.

## امکانات اصلی

- مدیریت گروه: بن، رفع بن، اخراج، اخطار، حذف اخطار، میوت، رفع میوت
- قفل‌ها: لینک، منشن، مدیا، استیکر، فوروارد، ضدفلود، پیام‌های سرویس
- جوین اجباری چندکاناله با بررسی تازه در هر تعامل کاربر
- خوشامد و قوانین قابل تنظیم
- فیلتر پاسخ خودکار و نوت گروه
- پنل ساده شیشه‌ای با دکمه‌های inline
- بکاپ ZIP از دیتابیس
- سیستم ادمین داخلی ربات با آیدی عددی یا فوروارد پیام کاربر
- دیتابیس SQLite با مدل SQLJSON
- تاریخ شمسی/جلالی در لاگ‌ها و بکاپ‌ها
- پرداخت کیف پول بله به‌صورت اسکلت آماده، ولی پیش‌فرض خاموش است

## نصب سریع روی VPS

```bash
unzip bale_group_manager_persian_commands.zip
cd bale_group_manager
cp .env.example .env
nano .env
```

در `.env` مقدارهای زیر را تنظیم کن:

```env
BOT_TOKEN=توکن_ربات_بله
OWNER_IDS=آیدی_عددی_خودت
CLEAR_PENDING_ON_START=1
```

بعد اجرا:

```bash
chmod +x run.sh
./run.sh
```

## نصب به‌عنوان سرویس systemd

```bash
cd bale_group_manager
cp .env.example .env
nano .env
chmod +x tools/install_service.sh
./tools/install_service.sh
```

مشاهده لاگ:

```bash
journalctl -u bale-group-manager -f
```

## دستورات فارسی اصلی

### راهنما و پنل

```text
راهنما
پنل
آیدی
آمار
بکاپ
```

### قفل‌ها

```text
قفل لینک
باز کردن لینک

قفل منشن
باز کردن منشن

قفل مدیا
باز کردن مدیا

قفل استیکر
باز کردن استیکر

قفل فوروارد
باز کردن فوروارد

قفل فلود
باز کردن فلود

قفل همه
باز کردن همه
```

این حالت‌ها هم پشتیبانی می‌شوند:

```text
لینک قفل شه
لینک باز شه
لینک را قفل کن
لینک را باز کن
```

### مدیریت کاربر

روی پیام کاربر ریپلای کن و یکی از این‌ها را بزن:

```text
بن
رفع بن
اخراج
اخطار اسپم
حذف اخطار
اخطارها
میوت 10 دقیقه اسپم
رفع میوت
```

با آیدی عددی هم کار می‌کند:

```text
بن 123456 دلیل
رفع بن 123456
میوت 123456 2 ساعت اسپم
```

مدت زمان فارسی و انگلیسی پشتیبانی می‌شود:

```text
10 دقیقه
2 ساعت
1 روز
10m
2h
1d
```

### خوشامد و قوانین

```text
تنظیم خوشامد سلام {first_name} عزیز
خوشامد روشن
خوشامد خاموش

تنظیم قوانین متن قوانین گروه
قوانین
```

متغیرهای قابل استفاده در خوشامد:

```text
{first_name}
{user_id}
{username}
{group_title}
{date}
```

### جوین اجباری

```text
جوین اجباری افزودن @channel عنوان
جوین اجباری حذف @channel
جوین اجباری لیست
```

### فیلتر و نوت

```text
افزودن فیلتر سلام | سلام عزیز
حذف فیلتر سلام
فیلترها

افزودن نوت راهنما | متن راهنما
حذف نوت راهنما
نوت راهنما
نوت‌ها
```

### ادمین‌های داخلی ربات

```text
افزودن ادمین 123456
حذف ادمین 123456
ادمین‌ها
```

## دسترسی‌های لازم ربات در گروه بله

ربات باید مدیر گروه باشد و حداقل این دسترسی‌ها را داشته باشد:

- حذف پیام‌ها
- مسدود/آزادسازی کاربران
- مشاهده اعضا برای جوین اجباری و بررسی عضویت کانال‌ها

## نکته‌های امنیتی

- توکن را داخل کد نگذار؛ فقط در `.env` قرار بده.
- فایل `.env`، دیتابیس و بکاپ‌ها داخل `.gitignore` هستند.
- دستورهای خطرناک `/eval` و `/sh` حذف شده‌اند.
- mute به‌صورت shadow mute است؛ یعنی پیام‌های کاربر میوت‌شده حذف می‌شود.

## قفل‌های فارسی و پنل شیشه‌ای

داخل گروه دستور زیر را بزنید:

```text
پنل
```

سپس وارد بخش «قفل‌ها» شوید و از دکمه‌های شیشه‌ای، هر قفل را خاموش/روشن کنید.

نمونه دستورهای متنی:

```text
قفل لینک
باز کردن لینک
قفل عکس
باز کردن عکس
قفل ویدیو
قفل شماره
قفل تبلیغ
قفل فلود
قفل پیام تکراری
قفل شبانه
قفل همه
باز کردن همه
```

برای فعال‌سازی قفل فحش، در فایل `.env` لیست کلمات را اضافه کنید:

```env
BAD_WORDS=کلمه۱,کلمه۲,کلمه۳
```
