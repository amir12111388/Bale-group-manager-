# آپدیت شخصی‌سازی از پیوی

این نسخه امکان شخصی‌سازی متن‌ها و اسم دستورها را برای هر گروه اضافه می‌کند. تنظیمات فقط داخل پیوی ربات انجام می‌شود و داخل گروه فقط دکمه ورود به پیوی نمایش داده می‌شود.

## شروع از داخل گروه

داخل گروه بزن:

```text
پنل
```

بعد دکمه زیر را بزن:

```text
🎨 شخصی‌سازی
```

ربات یک دکمه برای ورود به پیوی می‌دهد. اگر لینک پیوی ساخته نشد، دستور کپی‌شده را داخل پیوی ربات بفرست:

```text
شخصی سازی -100123456789
```

## شروع مستقیم از پیوی

داخل پیوی ربات بزن:

```text
شخصی سازی آیدی_گروه
```

مثال:

```text
شخصی سازی -100123456789
```

## قابلیت‌ها

- تغییر متن میوت، رفع میوت، بن، رفع بن، اخراج، اخطار، سقف اخطار
- تغییر متن عمومی حذف پیام توسط قفل‌ها
- تغییر متن مخصوص قفل‌هایی مثل لینک، تبلیغ، فوروارد، عکس، فحش، فلود
- تغییر اسم دستورها، مثل تبدیل `میوت` به `سیک`
- انتخاب لحن آماده: خودمونی، فان، جدی
- ریست کامل شخصی‌سازی‌ها برای برگشت به پیش‌فرض

## مثال کاربردی

از پیوی بخش `⌨️ اسم دستورها` را باز کن و برای میوت بنویس:

```text
سیک
```

بعد از بخش `🔇 متن عملیات‌ها`، متن میوت را اینطور تنظیم کن:

```text
{user} سیک شد 😂
دلیل: {reason}
تا: {until}
```

حالا داخل گروه، روی پیام کاربر ریپلای کن و بزن:

```text
سیک ۱۰ دقیقه اسپم داد
```

ربات همان عملیات میوت را انجام می‌دهد، اما با متن اختصاصی گروه جواب می‌دهد.

## متغیرهای قابل استفاده

```text
{user}      نام/آیدی کاربر
{user_id}   آیدی کاربر
{admin}     اسم مدیر
{admin_id}  آیدی مدیر
{reason}    دلیل
{time}      مدت
{until}     زمان پایان
{warns}     تعداد اخطار
{limit}     سقف اخطار
{action}    جریمه انجام‌شده
{group}     اسم گروه
{date}      تاریخ
```

## نکته دسترسی

فقط مالک ربات، مدیر گروه، یا مدیر داخلی ربات که دسترسی پنل دارد، می‌تواند متن‌ها و دستورهای همان گروه را تغییر دهد.
