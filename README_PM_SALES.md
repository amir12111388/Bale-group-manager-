# راهنمای فروش اشتراک از پیوی

## 1. پنل مالک

داخل پیوی ربات بزن:

```text
پنل مالک
```

از این بخش می‌توانی این موارد را تنظیم کنی:

- شماره کارت
- نام صاحب کارت
- متن راهنمای کارت‌به‌کارت
- توکن/مرچنت پرداخت بله
- روشن/خاموش بودن کارت‌به‌کارت
- روشن/خاموش بودن پرداخت بله
- پلن‌های اشتراک
- رسیدهای در انتظار تایید
- سفارش‌ها و آمار فروش

## 2. خرید اشتراک

داخل گروه فقط بزن:

```text
اشتراک
```

ربات وضعیت اشتراک گروه و پلن‌ها را نشان می‌دهد. خرید و پرداخت فقط داخل پیوی انجام می‌شود.

## 3. کارت‌به‌کارت

کاربر در پیوی پلن را انتخاب می‌کند، کارت‌به‌کارت را می‌زند و رسید را همانجا می‌فرستد.
مالک ربات رسید را در پیوی دریافت می‌کند و با دکمه تایید/رد تصمیم می‌گیرد.

## 4. پرداخت بله

اگر توکن/مرچنت پرداخت بله را از پنل مالک تنظیم و پرداخت بله را روشن کنی، کاربر می‌تواند داخل پیوی فاکتور بله بگیرد.
بعد از پرداخت موفق، اشتراک همان گروه خودکار فعال می‌شود.

## 5. لینک خرید از گروه به پیوی

ربات در شروع، یوزرنیم خودش را از API می‌گیرد. اگر دکمه خرید از گروه به پیوی درست کار نکرد، داخل پیوی مالک برو:

```text
پنل مالک > تنظیمات کلی > تنظیم یوزرنیم ربات
```

یا داخل `.env` مقدار `BOT_USERNAME` را بدون @ بگذار.
